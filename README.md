## Portfolio Deliverables

### 1. 📋 Information Security Risk Assessment
**File:** `GRC_Risk_Assessment_Acme.pdf` / `.docx`  
**Framework:** NIST Cybersecurity Framework (CSF) v1.1 + ISO 27001 risk scoring  
**Description:**  
A full information security risk assessment for a fictional mid-size SaaS company (150 employees, hybrid cloud). Includes:

- Executive summary with findings overview
- Defined scope and assessment objectives
- 5x5 likelihood/impact risk scoring matrix with color-coded thresholds
- 10-item risk register across asset categories (PII database, IAM, endpoints, cloud, third-party vendors)
- NIST CSF control gap analysis mapping each risk to a specific CSF subcategory
- Prioritized risk treatment plan with 30/60/90-day remediation timelines
- Risk summary table and formal sign-off block

**Skills Demonstrated:** Risk identification, likelihood/impact scoring, NIST CSF mapping, remediation planning, executive communication

### 2. 📄 Acceptable Use Policy (AUP)
**File:** `Acceptable_Use_Policy_Acme.pdf` / `.docx`  
**Framework:** ISO 27001 Annex A | NIST CSF | SOC 2 CC  
**Document ID:** IS-POL-001  
**Description:**  
A production-quality Acceptable Use Policy covering all critical policy areas expected in a SOC 2 or ISO 27001 audit. Includes:

- Document control table (version, dates, approvals, status)
- Formal revision history
- 10 policy sections: authorized use, prohibited activities, passwords/MFA, endpoint security, remote access, email, cloud services, social media, data classification, monitoring, violations, and exceptions
- 4-tier data classification matrix (Public / Internal / Confidential / Restricted)
- Violations enforcement matrix with consequences by severity
- Related policy document library cross-reference (IS-POL-001 through IS-POL-006)
- User acknowledgement and approval signature block

**Skills Demonstrated:** Policy writing, compliance documentation, data classification, enforcement framework design

### 3. 📊 SOC 2 Trust Service Criteria — Control Mapping Workbook
**File:** `SOC2_Control_Mapping_Acme.xlsx`  
**Framework:** AICPA SOC 2 Trust Service Criteria (TSC) 2017  
**Description:**  
A multi-tab Excel workbook mapping organizational security controls to SOC 2 Trust Service Criteria. Includes:

- **Dashboard tab** — executive compliance summary with control counts by status, compliance % by TSC category, and a prioritized gap register
- **CC – Common Criteria tab** — 20 controls mapped across all CC subcategories (CC1–CC9)
- **A – Availability tab** — 3 controls covering capacity, redundancy, and disaster recovery
- **C – Confidentiality tab** — 2 controls covering data identification and secure disposal
- Each control includes: TSC ID, requirement summary, control description, audit evidence, control owner, implementation status, gap notes, NIST CSF cross-reference, and target completion date
- Color-coded status system: Implemented (green) / In Progress (yellow) / Planned (orange) / Not Implemented (red)

**Skills Demonstrated:** SOC 2 TSC mapping, control design, audit evidence documentation, gap analysis, compliance tracking
